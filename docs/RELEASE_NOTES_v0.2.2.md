# 巡礼手帳 v0.2.2

v0.2.2 是一次前端与品牌体验小版本更新。搜索、选点、路线设置、路线预览、导航控制、首次导览和关于页采用统一的现代地图工具界面；路线算法、数据源、权限流程、Room schema、网络协议和导航服务行为保持不变。

## 安装与升级

- 支持 Android 8.0 及以上版本。
- 从 v0.2.1 更新时请直接覆盖安装，不要卸载或清除应用数据。
- 本版本没有 Room schema 迁移；导览状态、作品与点位选择、行程顺序、设置和导航进度会保留。
- 地图和新路线仍需要网络及设备上可用的 Google Play 服务。

## 主要变化

- 全面重做 Compose 展示层，统一浅色主题、信息层级、间距、圆角、状态提示和底部操作区。
- 搜索页改为清晰的搜索、作品列表、已选作品和下一步主线；修复短屏横屏时底部操作区可能被挤出屏幕的问题。
- 选点页突出地图和点位选择，宽屏采用列表与地图双栏；路线设置页重新分组出行方式、起点、终点和模式选项。
- 路线预览优先呈现地图、时间、距离、站点和主要操作；导航页只保留与当前道路或公交行程有关的控制。
- 首次导览与关于页改用统一品牌标识，并补强触控尺寸、选择语义、读屏状态和大字体适配。
- 应用图标和应用内品牌标识改为经授权、依据 Anitabi 官网 favicon 忠实矢量描摹的彩色轮廓，并支持 Android 13 主题图标。
- 修复本地 Debug 构建未从受忽略配置读取 Navigation API Key、导致真机地图只显示空白背景和 Google 水印的问题；正式构建的密钥与签名注入边界不变。
- 修复路线设置页出行方式内容在可滚动紧凑布局中贴近卡片上沿的问题。

## 无线路详情

- 当公交与步行都明确没有路线时，原红色错误卡会显示蓝色、加粗并带下划线的“详细信息”。
- 详情面板显示失败分段两端的名称、纬度和经度，帮助确认具体是哪两个点位没有数据。
- 用户主动点击后，可以把精确起终点交给手机上的 Google 地图，并自动预选公共交通模式；未安装 Google 地图时才回退到可处理该 HTTPS 链接的应用。
- 该入口只解释并核对既有错误，不会移动点位、替换路线结果或新增后台请求。

## 已知限制

- 本版本不支持中国大陆、日本和印度的公共交通路线；其他地区也只有在 Google Routes API 实际返回公交数据时才能规划。
- 消费版 Google 地图与开发者 Routes API 的数据和点位接入方式不同，因此 Google 地图可能找到本应用精确坐标请求没有返回的路线。“在 Google 地图中查看路线”用于核对，不代表应用已经修复该上游差异。
- 没有 Google Play 服务时，只能查看已保存的点位、顺序和进度，没有备用地图或路线服务。
- 步行和骑行道路导航仍会显示 Google 要求的测试版提示；请以现场道路、交通规则和安全状况为准。
- 个人每日额度、项目共享额度、网络和服务状态仍可能限制路线刷新；本地行程与进度不会因此被删除。

## 隐私

- Firebase 匿名身份、路线请求与可选遥测的边界没有改变。
- Google 路线、折线、步骤、预计时间和公交详情仍只保存在当前运行内存中。
- 只有用户在无线路详情中明确点击时，应用才会把该失败分段的精确起终点交给 Google 地图或设备上处理该链接的应用。
- Firebase Analytics 和 Crashlytics 仍默认关闭，可分别选择加入和撤回。
- 项目日志不会记录 Token、原始 IP、坐标、动画名称、搜索词或路线正文。

完整说明见 [隐私政策](https://github.com/realMisakaMikoto/junrei_navi/blob/main/PRIVACY.md)。
