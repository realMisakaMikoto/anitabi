- [x] 使用精确公开 RC4 在 Xiaomi 15T Pro 复现“无崩溃但地图回退到列表”；进程保持存活且崩溃缓冲区为空。
- [x] RC5 曾根据初步 AAR 检查在创建 `NavigationView` 前显式调用 `MapsInitializer.initialize`，并在调用失败时沿用安全回退。

- [x] 保留 RC3 的 Navigation SDK R8 类合并限制和反射注册器包访问修复，以及 RC4 的地图操作安全回退。
- [x] 真机失败后重新核对[官方 Navigation SDK 参考](https://developers.google.com/maps/documentation/navigation/android-sdk/reference/com/google/android/gms/maps/MapsInitializer)和 7.8.0 AAR 字节码：`MapsInitializer` 对 Navigation SDK 不适用，`NavigationView.onCreate` 会在内部正确阶段完成初始化；RC5 的外部提前调用属于错误修复方向。
- [x] 对 RC5 Release R8 产物做只读核验：Navigation SDK AAR 中的 `CreatorImpl` 原本包含公开无参构造，但 R8 `usage.txt` 明确记录该构造已被移除，`seeds.txt` 只保留类名。外部初始化会通过反射立即实例化这个已失去无参构造的类，确定性进入安全回退。
