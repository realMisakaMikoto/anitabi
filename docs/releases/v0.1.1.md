## 证据边界

- 实际签名 APK 的自动化证据覆盖安装、版本、冷启动、前台进程和崩溃缓冲。
- 完整离线导航状态流使用同一 `v0.1.1` 提交构建的 debug APK 和 instrumentation APK；不能把这一项误写成已对签名 APK 完成真实 GPS 或人工交互验收。
- `v0.1.1` tag 与自动 GPS 运行时测试提交之间没有生产源码或 Gradle 应用配置差异；差异仅为 CI、androidTest 和文档，但自动 GPS 仍是模拟器 test provider，不是真实定位硬件。
- 模拟器自动化不能替代实体手机上的定位硬件、扬声器、锁屏、厂商电源管理和真实移动网络。
