# v0.2.0 发布验收记录

结论：本版新增首次启动导览与多作品联合巡礼，并补齐 ORS 请求合同、错过换乘重算、权限错误和上游错误脱敏。发布仅在固定签名流水线与 Android 8/17 冷启动检查通过后成立。

## 已验证

- [x] 49 个 JVM 单元测试通过，0 failure/error/skipped；debug APK、androidTest APK 和 Lint 本地通过，Lint 为 0 项。
- [x] 首次启动门槛只有在定位、适用版本的通知权限和本机 ORS Key 都就绪后才能完成；权限缺失组合由单元测试覆盖。
- [x] CI 的全新安装冷启动会断言“初次使用设置”首屏，运行时导航夹具则明确写入测试专用 Key 并完成导览，不绕过生产逻辑。
- [x] 多作品选择、合并点位命名空间、标题前缀、道路/公交选点上限和规划入口由单元测试与 Xiaomi 15T Pro 的 3 部作品、178 点画面共同覆盖。
- [x] ORS Matrix/Directions 请求字段、三种道路 profile、上游错误脱敏和 Transitous 错过换乘宽限由确定性测试覆盖。
- [x] 发布包不包含共享 ORS Key；用户 Key 仍以 Android Keystore AES-GCM 加密，只存本机。

## 发布流水线

- `v0.2.0` tag 会运行 release 测试、Lint、R8、资源压缩、APK 内容审计、固定签名校验和 SHA-256 生成；任一步失败都不会创建 GitHub Release。
- Release 发布后会自动下载公开 APK，并在 Android 8/API 26 与 Android 17/API 37 上核对版本、冷启动、首次设置首屏、前台进程和空崩溃缓冲。
- 固定签名证书 SHA-256 预期为 `9679c83769368c7150f629d9cba3c0e5d633fa7f1043ce251fdba6c7c64fb00a`，与 v0.1.0–v0.1.4 相同。

## 真机与边界

- 导览加入前的 v0.2.0 同签名候选已在 Xiaomi 15T Pro（Android 16/API 36）原位升级并显示 3 部作品、178 个点，系统栏与手势栏无重叠，崩溃缓冲为空。
- 加入导览时手机未连接 ADB，所以首次设置页尚不能写成真机已通过；自动模拟器截图和后续真机复验必须与该边界分开记录。
- 用户已确认此前同一真机连续导航的中文 TTS 可以听到。真实 GNSS 长路线、长时间 OEM 省电和现实错过班次仍需在对应现场发生时验收。
- 聊天中曾暴露的旧 ORS Key 不属于项目资产，不写入源码、日志、文档、测试或发布包；所有者仍应撤销并重新生成。
