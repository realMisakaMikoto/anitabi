- RC APK 不得包含服务端 Google 凭据、VPS 密码、签名密码、ORS Key、Transitous/ORS/OpenFreeMap/MapLibre 请求路径或 keystore。
- 本记录不得写入 Token、坐标、动漫名、搜索词、路线正文、IP、服务账号或任何密码。
- 用户已明确禁止当前任务在其手机上安装任何内容；本 RC 只允许在 GitHub 模拟器和之后获得明确许可的覆盖安装验收中使用。
