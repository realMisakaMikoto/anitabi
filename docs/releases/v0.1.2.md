## 证据边界

- GitHub Actions 的干净出口成功只能证明官方 API 与客户端请求格式有效；它不能解除用户当前公网 IP 的 Cloudflare 封禁。
- 本版本没有加入代理、备用 Anitabi 域名或自动重试绕过，避免违反上游访问边界。
- 模拟器自动化不能替代实体手机上的定位硬件、扬声器、锁屏、厂商电源管理和真实移动网络。
