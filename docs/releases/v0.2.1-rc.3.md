- [x] 保留 RC2 已通过真机复测的异常响应多作品联合选择修复。

## 发布与真机门禁

- [x] 分支 CI 的 verify、API 26 和 API 37 作业通过。

- [x] 正式签名 `v0.2.1-rc.3` Prerelease 发布并通过签名、哈希和精确 APK 复验。
- [x] Xiaomi 15T Pro 不卸载、不清数据覆盖安装 RC3，确认既有选择、导览状态和权限保留。
- [ ] 点击“查看地图”后进程保持存活、地图界面可用且崩溃缓冲区为空。

RC3 修复了 Xiaomi 上由 R8 包访问破坏造成的崩溃，但没有达到地图功能验收。随后在另一台 Android 12 真机上，地图回调成功后应用在创建彩色点位图标时因 `IBitmapDescriptorFactory is not initialized` 崩溃。RC4 删除这项不必要的工厂依赖并补充地图操作兜底；RC3 不再继续验收。

## 安全边界

- 不记录 Token、IP、坐标、动漫名、搜索词、路线正文、服务账号、签名材料、VPS 凭据或任何密码。
- RC3 必须沿用公开 v0.2.0/RC1/RC2 的固定 RSA-4096 签名；不得在手机上混装调试签名包。
