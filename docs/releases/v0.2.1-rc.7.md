# v0.2.1-rc.7 验收记录

状态：RC6 真机地图崩溃的最小修复及本地门禁已完成；分支、主线、正式签名 Prerelease、精确公开 APK 兼容门禁和 Xiaomi 原位覆盖尚未执行。本候选在全部门禁通过前不得晋升为稳定版。

## 本候选修复

- [x] 对照 Google Navigation SDK 官方 `NavigationView` 生命周期参考、地图交互最佳实践、内存管理说明、发布说明及官方 Android 示例，确认本次 `GL-Map` 崩溃不是 API Key、路线参数或首次挂载顺序导致。
- [x] 从 SDK 7.8.0 AAR 与 RC6 Release 映射恢复完整调用链：渲染器使用 `Class.newInstance()` 创建着色器程序，R8 删除无参构造后返回空值并在渲染线程触发致命异常。
- [x] 仅保留 `com.google.android.libraries.geo.mapcore.renderer.ej` 子类中实际存在的无参构造，不修改地图业务逻辑或把独立生命周期改造混入本次根因修复。
- [x] 扩展 Release R8 审计，固定核验 SDK 7.8.0 的 12 个反射着色器类：类名和无参构造存在、构造器是 seed、`usage.txt` 未删除类或构造、通用保留规则进入最终配置。

## 安全边界

- 不记录 Token、原始 IP、坐标、动漫名、搜索词、路线正文、API Key、服务账号、签名材料、VPS 凭据或密码。
- RC7 必须沿用公开 v0.2.0 至 RC6 的固定 RSA-4096 签名；不得用调试签名包替代公开候选验收。
- 真机验收只使用 Xiaomi 15T Pro，不操作已排除的其他手机，不修改权限、模拟定位、网络、输入法、SSH 或密码设置。
- 地图未真实渲染时不得触发路线请求；任一门禁失败都停止稳定版晋升并保留 RC7 历史事实。
