# v0.1.4 发布验收记录

核对日期：2026-07-29

结论：v0.1.4 修复真机暴露的系统栏遮挡、正式 Anitabi 字段类型漂移、Transitous 有效路段显示 `0 m`、退化 LineString 和公交时区错误。源码候选已通过本地自动检查、Xiaomi 15T Pro 真机复验和 GitHub 主分支完整 CI；签名发布和签名 APK 兼容性结果将在工作流完成后补入本记录。

## 已通过并有直接证据

- [x] 搜索首页、点位选择、规划设置、路线预览、连续导航和关于页的顶部内容均使用状态栏 Insets；全应用根容器使用底部导航栏 Insets。
- [x] 1280×2772、Android 16/API 36 真机逐页截图确认顶部不再与状态栏重叠，规划、预览和导航按钮均位于系统手势条上方。
- [x] 正式 Anitabi 响应包含字符串 `ep: "CD"` 时不再导致整批解析失败；真机成功加载 Bangumi `#328609` 的 74 个有效点位。
- [x] Transitous 缺失/非正距离时从 polyline6 几何计算 Haversine 距离，并同步到路线腿和指令摘要；连续重复坐标被过滤，少于两个坐标的线不交给 MapLibre。
- [x] Transitous 站点 `tz` 已传入内部模型；UTC 时刻按站点 IANA 时区转为当地 `HH:mm`，新增 UTC→`Asia/Tokyo` 回归测试。
- [x] 正式 Transitous 真机路线包含 7 段、总计 47.2 km；铁路段显示 24.3 km 和 2.5 km，末段步行 781 m，日志无 `Invalid geometry in line layer` 和应用崩溃。
- [x] 用户个人 ORS Key 仅经应用输入并由 Android Keystore 加密保存；正式 HeiGIT API 成功生成约 0.8 km 道路路线。仓库、APK 构建配置、文档和日志不记录该值。
- [x] 本地 38 个 JVM 单元测试全部通过，0 failure/error/skipped；SDK 37 debug 编译、Lint 和 APK 内容审计通过。
- [x] 最终 debug 候选覆盖安装后，Android 报告 `versionCode=5` / `versionName=0.1.4`；冷启动成功，应用崩溃缓冲为空，Wi‑Fi 已恢复连接，导航服务和持续通知均已结束。
