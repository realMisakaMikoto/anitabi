# v0.2.1-rc.6 验收记录

状态：源码修复、本地门禁与后端部署已完成；正式签名 Prerelease、精确公开 APK 兼容门禁和 Xiaomi 真机验收待完成。本候选在全部门禁通过前不得晋升为稳定版。

## 本候选修复

- [x] 移除不适用于 Navigation SDK 的外部 `MapsInitializer` 调用，由 `NavigationView` 在内部正确阶段初始化地图运行时。
- [x] 窄保留动态 `CreatorImpl` 的公开无参构造，并新增 Release R8 审计，验证构造器、反射注册器包、类合并限制及应用源码中不存在 `MapsInitializer` 调用。
- [x] 仅在 `NavigationView` 已附着且生命周期可用时执行 `onCreate`、配置、启动、恢复和单次地图请求；销毁与成功创建严格配对，忽略释放后的迟到回调。
- [x] 选择地图和路线预览等待正尺寸视口并使用带宽高参数的边界相机更新；相机适配失败不再把整个地图运行时判定为不可用。
- [x] Google Routes 合法响应省略 route/leg 的 protobuf 零值字段时规范化为零；显式负值或错误类型仍然拒绝。
- [x] 公交首次及后续分段出发时间统一输出带秒和时区偏移的 RFC3339，避免秒数为零时在 Google 请求前被严格参数校验拒绝。
- [x] 网络传输失败提示明确说明当前网络出口可能被拦截，不再把正常网络下的出口封锁误写成普通断网。

## 安全边界

- 不记录 Token、原始 IP、坐标、动漫名、搜索词、路线正文、API Key、服务账号、签名材料、VPS 凭据或密码。
- RC6 必须沿用公开 v0.2.0 至 RC5 的固定 RSA-4096 签名；不得用调试签名包替代公开候选验收。
- 真机验收只使用 Xiaomi 15T Pro，不操作已排除的其他手机，不修改权限、模拟定位、网络、输入法、SSH 或密码设置。
- 地图未真实渲染时不得触发路线请求；任一门禁失败都停止稳定版晋升并保留 RC6 历史事实。
