# 巡礼手帖 v0.2.1

v0.2.1 将地图、道路导航和路线规划迁移到 Google 服务，并加入多作品联合巡礼、无限总点数分批规划、首次使用导览、版本化数据迁移和更可靠的导航恢复。

## 公共交通支持范围

**本版本不支持中国大陆、日本和印度的公共交通路线。原因是当前使用的 Google API 无法提供本应用在这些地区所需的公交数据，并非 Anitabi 主动屏蔽；短期内 Anitabi 也不计划另外接入第三方公交数据源。**

消费版 Google 地图与开发者 Routes API 的数据范围并不相同。Google 的[官方说明](https://developers.google.com/maps/faq#transit_directions_countries)明确排除日本的 Transit 合作方和印度铁路 IRCTC；中国大陆也无法通过本应用当前的 Google API 路径取得可用公交结果。即使 Google 地图能够显示当地公交，本应用也不一定能够取得相同结果。在上述地区请使用 Google 地图或当地交通应用查询公共交通。

其他地区的公交结果仍取决于 Google Routes API 的实际数据和服务可用性；应用不会把全步行路线伪装成公交路线。

## 安装与升级

- 支持 Android 8.0 及以上版本。
- 从 v0.2.0 更新时请直接覆盖安装，不要卸载或清除应用数据。
- 导览状态、作品与点位选择、行程顺序、设置和导航进度会保留。
- 本机保存的旧 ORS Key 和旧路线缓存会被移除；新路线需要联网刷新。

## 主要变化

- 地图、定位以及步行、骑行、驾车道路导航迁移到 Google Navigation SDK。
- 路线预览和公交规划迁移到 Google Routes，并通过项目自建服务保护服务器凭据和共享额度。
- 用户不再需要申请或填写 ORS Key，也不需要注册邮箱账号或提供姓名。
- 可以同时选择多部动画，并把所有巡礼点显示在同一张地图上。
- 行程总点数不再有固定的 8 点或 12 点上限；应用会自动排序和分批规划。
- 公交支持立即出发、指定出发、指定到达、交通方式偏好和逐段行程详情，但仅适用于上述不支持地区以外且 Google Routes 实际返回公交路线的地点。
- 修复全步行或空步骤被误报成公交、取消后请求仍继续、旧导航回调覆盖新状态、恢复进度不准确和长路线触发本地限速的问题。
- 路线服务失败时会保留本地行程和导航进度，并显示可恢复状态。

## 使用前需要知道

- 地图和新路线需要网络，以及设备上可用的 Google Play 服务。
- 没有 Google Play 服务时，只能查看已经保存的点位、顺序和进度，没有备用地图或路线服务。
- 步行和骑行路线会显示 Google 要求的测试版提示；请以现场道路、交通规则和安全状况为准。
- 公交不会启动 Google 原生公交导航，站台信息只显示上游实际提供的文字。
- “总点数不限”只表示保存与规划没有固定产品上限。个人每日额度、项目共享额度和设备资源仍会限制当天可刷新的路线；原生导航当前每个匿名用户每天最多预留 20 个目的地。
- 额度耗尽、网络中断或服务维护时，本地行程与进度不会被删除。

## 隐私

- Firebase 匿名身份只用于访问路线服务和计算共享额度。
- Google 路线、折线、步骤、预计时间和公交详情只保存在当前运行内存中。
- Firebase Analytics 和 Crashlytics 默认关闭，只有用户分别主动同意后才会启用，也可以随时撤回。
- 项目日志不会记录 Token、原始 IP、坐标、动画名称、搜索词或路线正文。

完整说明见 [隐私政策](https://github.com/realMisakaMikoto/anitabi/blob/main/PRIVACY.md)。
